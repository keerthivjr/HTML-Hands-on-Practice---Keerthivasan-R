What is .NET 8?

⚙️ Framework
  • Free, open-source platform by Microsoft
  • Cross-platform: Windows, Linux, macOS
  • LTS (Long Term Support) until November 2026
  • Successor to .NET Framework & .NET Core
▶ Runtime (CLR)
  • CLR – Common Language Runtime
  • Executes compiled C# (IL) code
  • Handles memory & garbage collection
  • JIT compiles to native machine code
📦 Ecosystem
  • NuGet – package manager
  • ASP.NET Core – web applications
  • MAUI – mobile & desktop
  • Blazor, EF Core, ML.NET & more

Variables & Type Inference

C# // Explicit Declaration int age = 25; string name = "Alice"; bool isStudent = true; // Type Inference with 'var' var score = 95; // int var city = "Chennai"; // string // Constants const double PI = 3.14159; const string APP = "MyApp"; // Nullable types int? x = null;
Naming Rules

Start with letter or underscore; case-sensitive; use camelCase for variables

var keyword

Compiler infers type at compile time — not dynamic. Type cannot change later.

const keyword

Value set once, never changes. Must be initialized at declaration.

Nullable Types (?)

Use int? x = null; — allows null for value types

Control Flow — if / else if / else

C# int marks = 75; if (marks >= 90) { Console.WriteLine("Grade: A"); } else if (marks >= 75) { Console.WriteLine("Grade: B"); } else { Console.WriteLine("Grade: C"); }
1. Condition (bool)

Expression inside () must evaluate to true or false

2. else if

Chain multiple conditions — only the first true block runs

3. else

Fallback when no condition is true — optional but good practice

💡 Best Practice: Always use braces { } even for one-line blocks to avoid bugs
07

Control Flow — switch Statement

Traditional Switch

C# int day = 3; switch (day) { case 1: Console.Write("Mon"); break; case 2: Console.Write("Tue"); break; default: Console.Write("Other"); break; }

Switch Expression (C# 8+)

C# string result = day switch { 1 => "Monday", 2 => "Tuesday", 3 => "Wednesday", _ => "Other Day" };
Key Points:
• break exits the case in traditional switch
• _ is the default wildcard in switch expressions
• Switch expressions are cleaner — prefer in C# 8+
08

Control Flow — Loops

for loop
for (int i = 0; i < 5; i++) { Console.Write(i); } // Output: 0 1 2 3 4
Use when number of iterations is known
while loop
int n = 1; while (n <= 3) { Console.Write(n); n++; } // Output: 1 2 3
Checks condition before each iteration
do-while loop
int x = 1; do { Console.Write(x); x++; } while (x <= 3); // Runs at least once!
Checks condition after — runs minimum once
foreach loop
int[] nums = {1,2,3}; foreach (int n in nums) { Console.Write(n); } // Output: 1 2 3
Best for iterating collections & arrays
09

Conditional Operators

Ternary Operator — condition ? value_if_true : value_if_false
string status = (age >= 18) ? "Adult" : "Minor";
Null-Coalescing Operator — ?? returns right side if left is null
string name = userInput ?? "Guest"; // If null → "Guest"
Null-Coalescing Assignment — ??= assigns only if null (C# 8+)
userInput ??= "Default"; // Same as: if (userInput == null) userInput = "Default";
💡 Quick Tip: Ternary replaces simple if-else in one line. Use it for clarity, not complex logic — don't nest ternaries!

Key Takeaways

01
.NET 8 is Microsoft's free, cross-platform runtime. C# code compiles to IL, executed by the CLR.
02
C# is strongly typed — choose the right data type (int, double, string, bool) for your data.
03
Use var for type inference, const for unchanging values, and ? for nullable types.
04
if-else handles branching; switch is cleaner for multiple fixed value checks.
05
Loops: for (known count), while (condition-first), do-while (run once), foreach (collections).
06
Ternary (?:) shortens if-else; ?? handles null safely; ??= assigns only when null.
